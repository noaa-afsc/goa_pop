Structural Updates

Code for the November model runs is available on github.

Previously, the catch component of the negative log-likelihood (\(\text{nLL}\)) was evaluated using a weighted sum-of-squares (ssqcatch) on log-transformed catch data padded with a small constant (\(g = 10^{-5}\)) to prevent \(\log(0)\) errors: \[\text{ssqcatch} = \sum_y w_{\text{catch}, y} \left( \log(C_{\text{obs}, y} + g) - \log(\hat{C}_{\text{pred}, y} + g) \right)^2\] where \(C_{\text{obs}, y}\) is the observed catch (catch_obs), \(\hat{C}_{\text{pred}, y}\) is predicted catch (catch_pred), and \(w_{\text{catch}, y}\) (catch_wt) was a fixed annual weight set to \(50.0\).

This formulation omitted normalizing constants and implicitly assigned observation uncertainty via the weight multiplier \(w_{\text{catch}}\) rather than an explicit coefficient of variation (\(\text{CV}\)). In the RTMB implementation, catch likelihoods are evaluated using the full normal probability density function on log-transformed catches (\(\log(C_{\text{obs}} + g) \sim \mathcal{N}(\mu, \sigma_c^2)\)): \[\text{like\_catch} = -\left[ \sum_y \ln f_{\mathcal{N}}\left( \log(C_{\text{obs}, y} + g) \,;\, \mu_y, \sigma_{c, y} \right) \right] \times w_{\text{catch}}\] where the mean is \(\mu_y = \log(\hat{C}_{\text{pred}, y} + g)\), and the log-scale standard deviation \(\sigma_{c, y}\) (sigma_catch) is derived directly from an input catch CV (catch_cv): \[\sigma_{c, y} = \sqrt{\log(\text{catch\_cv}_y^2 + 1.0)}\] Under this formulation, catch_wt is set to \(1.0\), and catch observation uncertainty is explicitly specified using an input CV of \(0.10\) (which corresponds to the \(\sim 10\%\) CV implied by the legacy weight of 50). Log-normal bias correction is omitted for catch because its high precision renders the bias term negligible.

The specific code changes for the catch likelihood are:

## catch ----
Cat <- Fat / Zat * Nat * (1 - Sat)
catch_pred <- colSums(Cat * waa)
switch(
  like_type,
  "admb" = {
    ssqcatch <- sum(catch_wt * (log(catch_obs + g) - log(catch_pred + g))^2)
  },
  "rtmb" = {
    sigma_catch <- sqrt(log(catch_cv^2 + 1.0))
    like_catch <- -sum(RTMB::dnorm(
      log(catch_obs + g),
      log(catch_pred + g),
      sigma_catch,
      log = TRUE
    )) *
      catch_wt
  }
)

where catch_wt = 50 for each year in the ADMB version. To the full lognormal distribution, where catch_wt = 1.0 and a CV of 0.1 is provided for each year.

Previously, the survey biomass negative log-likelihood (\(\text{nLL}\)) was evaluated using a simplified sum-of-squares approximation of the log-normal distribution:

\[\text{nLL} = \lambda \sum_y \frac{\left( \log(I_y) - \log(\hat{I}_y) \right)^2}{2 \cdot \text{CV}_y^2}\] where \(I_y\) is the observed survey index (srv_obs), \(\hat{I}_y\) is the predicted biomass (srv_pred), and \(\text{CV}_y = \frac{\text{SE}(I_y)}{I_y}\) (srv_sd / srv_obs). This formulation omits normalizing constants and does not account for a log-normal bias correction term (\(\frac{1}{2}\sigma^2\)) often used to ensure the model’s arithmetic expectation aligns with predicted survey biomass. In the updated RTMB implementation, survey index likelihoods are evaluated using the built-in normal density function on the log-transformed observations, \(\log(I_y) \sim \mathcal{N}(\mu_y, \sigma_y^2)\):

\[\text{nLL} = -\lambda \sum_y \ln \left[ f_{\mathcal{N}}\left(\log(I_y) \,;\, \mu_y, \sigma_y\right) \right]\] where the log-scale standard deviation \(\sigma_y\) (log_sd) is calculated as:

\[\sigma_y = \sqrt{\log(1 + \text{CV}_y^2)}\] The location parameter \(\mu_y\) (mu) includes a configurable bias correction toggle (do_bias_correct):

\[\mu_y = \begin{cases} \log(\hat{I}_y) - \frac{1}{2}\sigma_y^2 & \text{if } \texttt{do\_bias\_correct} = \text{TRUE} \\ \log(\hat{I}_y) & \text{if } \texttt{do\_bias\_correct} = \text{FALSE} \end{cases}\] Because RTMB::dnorm() incorporates normalizing terms (\(\log(\sigma_y) + \frac{1}{2}\log(2\pi)\)) and optionally applies the bias-correction offset, total \(\text{nLL}\) values will differ by a constant shift compared to the legacy formulation.

The changes to the code in the model were:

## survey biomass ----
isrv <- 1
srv_like <- 0.0
for (t in 1:T) {
  if (srv_ind[t] == 1) {
    srv_pred[isrv] <- sum(Nat[, t] * slx_srv * waa) * q

    switch(
      like_type,
      "admb" = {
        srv_like <- srv_like +
          (log(srv_obs[isrv]) - log(srv_pred[isrv]))^2 /
            (2 * (srv_sd[isrv] / srv_obs[isrv])^2)
      },
      "rtmb" = {
        log_sd <- sqrt(log(1 + srv_cv[isrv]^2))

        # Toggle bias correction on or off
        if (do_bias_correct) {
          mu <- log(srv_pred[isrv]) - 0.5 * log_sd^2
        } else {
          mu <- log(srv_pred[isrv])
        }

        srv_like <- srv_like -
          RTMB::dnorm(log(srv_obs[isrv]), mu, log_sd, log = TRUE)
      }
    )
    isrv <- isrv + 1
  }
}
like_srv <- srv_like * srv_wt # weighted survey likelihood

Previously, the negative log likelihoods (nLL) for the age and size composition data (fishery and survey) were calculated using a manual sum-of-logs approximation of the multinomial distribution. Observed and predicted proportions were padded with a small constant (\(g = 10^{-5}\)) to prevent \(\log(0)\) evaluation errors, and an explicit offset term was subtracted so that a perfect fit evaluated to zero:

\[\text{nLL} = -\sum_{t} \text{ISS}_t \sum_{a} (p_{\text{obs}, t, a} + g) \log(p_{\text{pred}, t, a} + g) - \text{offset}\] where \(\text{ISS}_t\) is the input sample size in year \(t\), \(p_{\text{obs}, t, a}\) is the observed proportion at age/size \(a\), \(p_{\text{pred}, t, a}\) is the predicted proportion, and \(\text{offset} = -\sum_{t} \text{ISS}_t \sum_{a} (p_{\text{obs}, t, a} + g) \log(p_{\text{obs}, t, a} + g)\).In the updated RTMB implementation, composition likelihoods are evaluated using RTMB::dmultinom().

To match the input requirements of dmultinom:

  • Observed proportions (\(p_{\text{obs}}\)) are scaled by the input sample size (\(\text{ISS}_t\)) to generate observation counts (\(x = p_{\text{obs}} \times \text{ISS}_t\)).
  • Predicted proportions (\(p_{\text{pred}}\)) are padded with \(g\) and re-normalized so that probabilities sum strictly to 1.0.

Because RTMB::dmultinom() evaluates the complete multinomial density function (including normalizing factorial terms), explicit offset calculations are omitted (\(\text{offset} = 0\)).

The code changes for the composition likelihoods (using fishery age as an example) were:

## fishery age comp ----
fish_age_lk <- 0.0
offset <- 0.0
icomp <- 1
for (t in 1:T) {
  if (fish_age_ind[t] == 1) {
    # base predictions (shared between both likelihood types)
    fish_age_pred[, icomp] <- colSums((Cat[, t] / sum(Cat[, t])) * age_error)

    switch(
      like_type,
      "admb" = {
        offset <- offset -
          fish_age_iss[icomp] *
            sum((fish_age_obs[, icomp] + g) * log(fish_age_obs[, icomp] + g))

        fish_age_lk <- fish_age_lk -
          sum(
            fish_age_iss[icomp] *
              (fish_age_obs[, icomp] + g) *
              log(fish_age_pred[, icomp] + g)
          )
      },
      "rtmb" = {
        # add constant 'g' and re-normalize so probabilities sum to 1
        pred_prob <- fish_age_pred[, icomp] + g
        pred_prob <- pred_prob / sum(pred_prob)
        # convert observed proportions to "counts" using the input sample size
        obs_counts <- fish_age_obs[, icomp] * fish_age_iss[icomp]
        fish_age_lk <- fish_age_lk -
          RTMB::dmultinom(x = obs_counts, prob = pred_prob, log = TRUE)
      }
    )
    icomp <- icomp + 1
  }
}


# offset shifts ADMB likelihood so a perfect fit = 0.0 (stays 0.0 for RTMB)
fish_age_lk <- fish_age_lk - offset
like_fish_age <- fish_age_lk * fish_age_wt

Last, the manually coded log-densitity formulations of prior penalities on natural mortality (M), catchability (q), and recruitment variability (\(\sigma_R\)), were updated to use the RTMB’s built-in statistical function, RTMB::dnorm. The only mathematical difference between these formulations is that the manual version drops the normalization constant term (\(\log(\sigma \sqrt{2\pi})\)). Consequently, the parameters point estimates will generally remain identical, but the total nLL value will shift by a constant offset.

The code changes were as follows:

if (like_type == "admb") {
  nll_M <- (log(M) - log(mean_M))^2 / (2 * cv_M^2)
  nll_q <- (log(q) - log(mean_q))^2 / (2 * cv_q^2)
  nll_sigmaR <- (log(sigmaR / mean_sigmaR))^2 / (2 * cv_sigmaR^2)
} else {
  nll_M <- -RTMB::dnorm(log(M), log(mean_M), cv_M, log = TRUE)
  nll_q <- -RTMB::dnorm(log(q), log(mean_q), cv_q, log = TRUE)
  nll_sigmaR <- -RTMB::dnorm(
    log(sigmaR / mean_sigmaR),
    0,
    cv_sigmaR,
    log = TRUE
  )
}
